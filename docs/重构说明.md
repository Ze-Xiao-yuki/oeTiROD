# 重构说明与来源边界

修改后的项目根目录直接保留`nanodet/`检测库，其余功能按报告拆分。原项目脚本、附带检查点及说明另存同级`TiROD_原代码存档/`，原文件SHA256记录在`upstream_manifest.json`。

保留检测库中的兼容补丁只有两处：`nanodet/data/collate.py`去除PyTorch 2.x已删除的`torch._six`导入；`nanodet/data/dataset/coco.py`改用`imdecode/fromfile`支持Windows中文图像路径。新训练流程调用NanoDet检测器与COCO数据集，不运行原有顶层训练脚本。

## 原脚本到公共模块

| 原有处理 | 新位置或处理 |
|---|---|
| 各脚本重复`create_exp_cfg`、作者绝对路径 | `configs/` + `train_eval/config.py`，路径由配置文件位置解析 |
| 导入脚本立即开始十任务训练 | `run.py`和`tools/run_all.py`具有main保护 |
| FT、REP、TREP等重复训练器 | `train_eval/engine.py`统一训练生命周期 |
| 回放缓冲固定返回容量、对小任务随机抽样越界 | `TaskBalancedBuffer`按实际大小返回，配额不超过可用样本 |
| 分别拼接两个DataLoader，历史批次不足即中止 | `MixedBatchSampler`有限批次、当前样本每轮访问一次，历史有放回抽样 |
| `task > 9`等跳过大部分任务的训练条件 | 每个任务都训练并评估，首任务也形成矩阵对角线 |
| 复制作者本机的首任务检查点 | 默认从同种子初始化，可显式指定兼容的初始权重 |
| 后续任务用test作为val | train/val/test独立，验证只选模型，测试只生成任务结果 |
| 固定`cuda:2` | 统一`--device`参数 |
| EWC对检测输出使用分类交叉熵、缺失训练器导入/错误数据时序 | 当前任务结束后用检测损失梯度估计Fisher，后续任务累计参数约束 |
| 教师网络未固定推理状态 | 任务开始复制上一模型，`eval()`、禁用梯度，训练时保持冻结 |
| KMeans中心可能选中同一图像多次 | 本地确定性KMeans与不重复代表索引；使用ResNet50倒数层特征 |
| 原YAML重复schedule/evaluator/log | 干净配置与重复键拒绝检查 |
| 原README部分大小写与潜在回放文件名错误 | `methods/registry.py`给出十个准确的原入口 |

## 方法细节

FT只使用当前数据；CUMUL累计此前全部训练数据；REP按任务配额随机保留；TREP按序列位置等距取样；KMREP对本地ResNet50特征做聚类代表选择。回放容量是图像数量，不是字节预算。

LREP保留原入口的冻结骨干+原图回放逻辑；LD使用冻结骨干与分类/中间层蒸馏；SID使用分类及检测头卷积塔中间特征蒸馏；LWF匹配完整检测头输出。未凭方法名称擅自实现另一篇论文的算法。

EWC采用**批次平均检测损失梯度平方的对角近似**，在任务末固定模型上估计，默认最多32批。它不是逐样本精确Fisher；参数强度与批次数均可调整。约束保存于连续运行的策略对象中；本版不提供跨进程恢复整个持续学习状态，`last_epoch.pt`只保留训练状态快照，不应宣称可完整恢复回放/蒸馏/EWC序列。

新流程是工程重构与修复，不保证逐位复现原论文数值：输入预处理、KMeans特征层/归一化、Fisher估计、任务训练与验证规则均有明确调整。原入口保留供对照。

## 项目模块

十种对照方法默认使用`profile: baseline`；报告的模块组合用`profile: project`、`--method REP`。项目回放库使用已标注训练图像的索引、场景/类别覆盖和64维描述去重，PM保存真实模型快照。

多专家的共享计算只执行一次，推理按每张图像路由到一个检测头。训练使用任务场景对应的专家编号，回放样本保留原编号以监督路由；检测损失约束当前适配专家。此处场景编号只是训练标签，推理不读取任务标签。

微睡眠维护当前在任务训练结束后的独立维护窗口执行，默认关闭。先测固定验证基线，再开始预算计时；计时覆盖参数处理与维护后的验证，完成后超预算则回滚。单个GPU内核和验证函数调用不能强制中断，预算是停止/回滚判据，不能承诺操作系统级硬实时。该模块不启动后台服务或操作桌面。
